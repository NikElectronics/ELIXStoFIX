## 📋 О проекте

Модуль диагностики позволяет получать детальную информацию о состоянии аккумуляторов Makita LXT и Makita XGT, их характеристиках и параметрах  через удобный WEB-интерфейс.

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🔍 **Диагностика состояния** | Полный анализ состояния аккумулятора |
| 📊 **Чтение данных** | Получение информации  |
| 🌐 **WEB-интерфейс** | Удобный браузерный интерфейс |
| 📈 **Параметры батареи** | Напряжение, емкость, температура и др. |
